# 音乐、音效与播报

声音全部在静态页面内播放，不需要后端。浏览器需要首次点击或按键解锁音频，默认开启；选项中的总音量与全部静音会保存到浏览器。

## 地图音乐

在 `js/audio.js` 的 `MUSIC` 表配置每张地图的主题：

| 地图     | 曲名     | 速度    | 风格                         |
| -------- | -------- | ------- | ---------------------------- |
| 夕照天台 | 烈日决斗 | 148 BPM | 热血电子摇滚式旋律、八度低音 |
| 午夜天台 | 霓虹追击 | 138 BPM | 暗色合成器、切分琶音         |
| 训练空间 | 极限热身 | 126 BPM | 明亮电子节拍、轻快训练旋律   |

这些是原创程序谱曲，由 Web Audio 实时演奏鼓组、低音、和弦与旋律，不是音乐服务提供的录音。大厅、模式、选项与图鉴循环《街机集结》（120 BPM），选角和地图规则页循环《准备出击》（132 BPM），进入比赛后切换地图主题，结束演出保持地图音乐，结算选项循环《再战时刻》（112 BPM）。暂停保留 BGM；返回选角、回大厅或重开会切换到对应主题，不叠放旧曲。

## 音效事件

- `playMove()`：挥空与蓄势（大招不触发语音播报）。
- `releaseMove()`：实际进入有效帧才播放气功、抓取、爪击等释放声音；被打断不会误放释放声。
- `impact()`：根据防御、普通命中、大招、抓投区分材质与低频力度。
- `finisher()`：最终一击的低频冲击与噪声尾音。

总线使用动态压缩防止叠加时过载，音源结束后释放节点。播报时降低音乐，保持语言清晰。

## 播报素材

`assets/audio/announcer/` 内是已生成的英语合成语音 WAV，并非真人激情配音。运行时加入低音色调整、饱和母带与短回声，营造街机播报感。无需用户电脑安装对应声音。

共 13 条播报。同名文件可以替换为自行录制的真人配音。保留文件名和短句时长，尤其是 `round`、`one/two/three`、`fight` 应在 0.6 秒以内，`ko` 应在 0.9 秒以内，字母间静音不超过 0.1 秒。KO 按原速播放，不再额外拉慢。引擎不叠放播报，后来的重要播报会替换前一条。

单人挑战中，1P 获胜播放 `winner`（You win），2P 获胜播放 `loser`（You lose）并用下降音型收尾；本地双人、观战和练习按获胜方播放 `p1win` / `p2win`（Player one / two wins）。结束大字同步展示实际结果。

在安装了 Microsoft David Desktop 的 Windows 上重新生成：

```powershell
powershell.exe -NoProfile -STA -File tools/generate-announcer.ps1
python tools/process-announcer.py
npm run build
```

处理脚本会裁掉首尾静音、压缩 KO 内部长停顿，做轻度饱和、归一化与边缘淡入淡出。先生成原始录音，再运行处理脚本一次。仅更新部分文件时，生成脚本可传 `-Keys` 数组，处理脚本可传对应名称，例如 `python tools/process-announcer.py ko loser p1win p2win`，避免重复处理其他母带。

## 结束演出

`js/round-ending.js` 定义 5.2 秒时间线：最后一击停顿和亮闪 → 身体落地 → KO／时间结束／平局大字及播报 → 胜利大字及播报 → 结算选项或下一回合。角色只画一个不透明姿态，不使用拖影。演出期间不执行攻击、碰撞与伤害；暂停会冻结演出。

浏览器测试通过真实 AI 对战走到 KO，检查语音资源解码、倒地阶段、期间生命不变、结算延后出现、各页面 BGM 切换和单人失败播报。`snapshot().audio` 提供只读播放状态用于排查。

挥空与受击改用 `assets/audio/combat/` 中的 27 个原创短采样（9 类，各 3 个变体），包括拳／脚／爪的破风、拳击、踢击、重击、气功命中、抓摔和防御。命中由低频身体冲击、中频接触声与高频短促爆裂组成，干声收尾，不使用提示蜂鸣替代打击。每次轮换采样与轻微音高；运行 `node tools/generate-combat-sfx.mjs` 可重新生成。大招保留蓄力和释放音效，不再语音喊招。

`superStart()` 专门在成功发动大招时播放冲击、金属亮音与上升蓄能，与短时停和收镜同帧触发，不播报人声；`releaseMove()` 仍按实际有效帧播放释放声。
