# 方向拳脚动作 V4

使用内置 imagegen，以 `arcade-fighters.png` 为造型参考生成并应用：

- `assets/characters/direction-attacks-v4.png`：1086 × 1448，双方突进重拳、上勾拳、飞踢，每招四帧。
- `assets/characters/sweeps-v4.png`：1774 × 887，双方下段扫腿，每招四帧。

提示词要求：保留蓝衣白裤黑发、红衣黑裤棕发的原人物造型与像素街机风格，朝右，透明 PNG，无文字、网格或拖影；每招有蓄势、出手、命中、恢复。突进重拳需要转腰踏步，勾拳从低位上挑，飞踢屈膝后向前伸腿，扫腿单手撑地、躯干压低、伸腿沿地面扫出。姿势和相邻行列之间保留透明空隙。

实际输出尺寸与行数没有严格遵循提示词，因此按检查后的真实行列坐标裁切，不能直接等分图片。映射位于 `js/animation-data.js`，角色配置末尾不得再用普通拳脚覆盖这些映射。
