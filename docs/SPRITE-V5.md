# 技能一与大招动画 V5

通过内置 imagegen 生成，参考 `arcade-fighters.png` 锁定两名原创角色造型。最终应用文件位于 `assets/characters/`：

- `canglan-skill-v5.png`：三波掌推的蓄力、释放和收招。
- `canglan-skill-mid-v5.png`：独立的半伸臂过渡来源，只使用第 3 个隔离姿势。
- `canglan-super-v5.png`：低位准备、举手、头顶聚气、回落、推掌和复位。
- `chifeng-skill-v5.png`：抓取、短拳连打、抬膝和抛摔。
- `chifeng-super-v5.png`：突进抓取、连续重击、抬起和重摔。

生成提示词：保留蓝衣白裤黑发、红衣黑裤棕发的像素街机人物形象，六个连续全身姿势，面朝右，透明背景，无文字、网格、受害者、拖影、光球和粒子。所有帧维持相同头部、躯干、四肢比例，脚底保持基准。蓝色技能一为准备、髋侧蓄力、半伸臂、双掌推出、收回、复位；蓝色大招为准备、抬臂、头顶聚气、下落、推掌、恢复；红色技能一为警戒、伸手、抓握、短拳、抬膝、摔出；红色大招为蓄势、前扑、抓握、重拳、抬起、下摔。重新排版为三列两行，1536×1024，各姿势独占单格且四周留透明间距。

帧图不包含气功波或打击光效，这些由战斗特效层绘制。每个图集固定人物比例，不按举手后的外接高度重新缩放。`originY` 单独标定脚底位置，避免两行图集基准不同导致人物悬浮。赤锋的 `grabTimeline` 按实际命中时刻选帧；帧切换仍为单个人物、不透明渲染。

苍岚二技能范围由 220 增至 280，只击飞，不造成倒地；赤锋二技能范围由 150 增至 200，保留落地伤害与击倒。伤害与能量消耗保持配置原值。
