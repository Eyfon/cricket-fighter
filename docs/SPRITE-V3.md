# 技能与倒地图集 V3

素材：`assets/characters/skill-knockdown-v3.png`，1536 × 1024，RGBA 透明 PNG。
通过内置 imagegen 生成并编辑，参考 `arcade-fighters.png` 保留两名角色的造型。

最终提示词：保留原像素街机人物造型、服装与配色；六列四行，每格一个完整姿势、透明间距、面向右、不加文字和拖影。第一行苍岚下蹲蓄力、双拳握紧屈臂在胸侧、绷紧爆发蓝色气焰、恢复；第二行赤锋前倾起跳、举拳跃起、空中收拳、下降下砸、拳头触地火花、恢复；第三和第四行分别为苍岚、赤锋受击后仰、屈膝失衡、向后跌倒、臀部落地、侧躺、撑地起身。清除背景、保持实际透明通道、姿势与特效不跨格。

生成结果并非严格等高行，实际裁切由 `js/animation-data.js` 按行边界 0–292、294–574、576–781、787–1005 配置，各列宽 256。不要按 256 高度直接等分，否则会串入相邻动作。角色基准位置与比例在运行时单独配置。

赤锋二技能根据实际垂直速度采样上升、最高点、下落帧；只有落地才使用触地帧，保留短暂恢复动画。倒地按倒地计时采样六帧，并在播放期间限制行动。
