# 界面与比赛流程

## 页面

大厅统一采用全屏街机菜单壳：深蓝背景、荧黄当前项、左右蓝红阵营、切角确认按钮。主页使用“蛐蛐乱斗”游戏标题、可操作菜单列与动态角色立绘；模式页使用对战标识，选角不展示技能，地图和规则保留同屏。避免宣传文案、网站导航和外部网站式页脚。图鉴与设置沿用同一视觉系统。

主页、模式和图鉴支持方向键切换当前项、Enter 确认；非战斗菜单支持 Esc 返回上一级。对战参数与设置开关使用「< 当前值 >」左右按钮，总音量使用滑动条；Tab 聚焦、Enter/空格确认，隐藏的原始输入只保存配置值，选角方向键仍在角色池内切换角色。手机使用点选；不显示顶部品牌导航行、底部页脚和操作提示，让菜单内容占满可用高度。各菜单固定在可用游戏区域内，设置、说明、图鉴和技能详情在各自内容区域滚动；头部返回和主要操作始终可达。界面短暂淡入与位移遵循系统减少动态效果偏好，不影响战斗动作。

`style/game-shell.css` 负责统一菜单外观；`style/match-lobby.css` 提供选角和地图布局，战斗与触控继续由原有样式管理。

- 主界面：开始对战、练习模式、角色图鉴、游戏选项。
- 模式选择：电子斗蛐蛐、单人挑战、本地双人。
- 手机模式页仅显示电子斗蛐蛐与单人挑战，两张紧凑卡片居中并列并略微上移，高度不随页面无限拉伸；本地双人入口仅在电脑显示。
- 角色选择：中间共享角色池、左右双方待机预览；1P 先选择并锁定，再轮到 2P，双方锁定后进入地图页。允许选择相同角色，可随机选择当前方，锁定方可点击“重选”。只显示角色图片与名字，不显示技能。
- 地图与对战设置：同一页左侧为纵向滚动地图卡片，点击后中间预览完整场景（等比包含，不裁掉边缘），右侧设置回合时间、获胜回合数、双方统一血量倍率、AI 难度。对战设置采用「< 当前值 >」按钮，按枚举顺序调整，到边界禁用对应按钮，不弹出原生选项卡；练习对手同样使用按钮，无限能量点开关位于双方血量倍率右侧，仅在练习模式显示；练习时间与获胜回合锁定。手机横屏下规则区域独立滚动，底部比赛摘要与开战按钮始终可见。
- 战斗：VS / 回合开场、血条、蓄能进度与三点能量、Esc 暂停、手机按键。
- 结算：只有“返回”和“重新开战”两个按钮。
- 图鉴：桌面和手机横屏均为每行三张紧凑角色卡，卡片宽度上限 280 像素，立绘等比完整显示；增加角色自动换行，列表区域独立滚动。列表只显示角色图片与名字。点击进入独立详情页，读取配置展示普攻、招式1、招式2、特技、绝招，不显示按键；伤害为配置实际伤害。
- 选项：静音、震屏、扫描线、手机按钮显示与方向操作通过左右箭头点按调节，到边界禁用；总音量使用滑动条并显示百分比，以 5% 为步长即时保存，恢复默认同步更新显示值。切换全屏与恢复默认设置使用等大按钮，不显示浏览器保存提示；右侧仅保留操作说明，不提供判定框开关。

正常流程：主界面 → 模式 → 角色 → 地图与规则 → 战斗 → 结算。
练习流程：主界面 → 角色 → 地图与规则 → 练习。

## 默认规则与取值

| 项目 | 默认 | 可选 |
| --- | --- | --- |
| 回合时间 | 60 秒 | 30 / 60 / 90 秒 / 无限 |
| 获胜所需回合 | 2 胜 | 1 / 2 / 3 胜 |
| 双方统一血量倍率 | 1 倍 | 1 / 2 / 3 / 5 倍 |
| AI 难度 | 正常 | 简单 / 正常 / 困难；观战双方独立选择 |
| 地图 | 夕照天台 | 夕照天台 / 午夜天台 / 训练空间 |

基础生命统一为 100，内部最大生命=100×倍率。所有招式在配置中直接填写低伤害，结算直接使用 damage，普通近战、气功波、爪击与抓取每段都不再统一折算。普通防御默认受到该次伤害的 25%，抓取与破防招式仍造成完整伤害。

双方共享一个倍率，没有单独调整左右方生命的控件。战斗只显示血条比例，不绘制生命数字。角色招式表的伤害数字不受此限制。

观战显示 1P 与 2P 两个独立 AI 难度调节器；人机只显示对手难度，本地双人与练习隐藏 AI 难度。设置保存在当前浏览器，重新开战沿用双方难度。难度影响延迟感知、防守、距离、合法接招、资源选择与近期记忆，不改变角色数值。详见 [AI 规范](./AI-SPEC.md) 和 [实测对比](./AI-COMPARISON.md)。

午夜天台是夕照天台的冷色夜景版本，复用同一场景布局与原图。训练空间使用程序绘制的网格，地图只改变视觉，不改变判定和伤害。

## 生命周期

- 点击开始后将角色、地图、时间、倍率、获胜目标等复制为本场配置，比赛中不读取正在编辑的菜单控件。
- VS 开场后进入比赛；时间到按剩余生命判断回合胜负，平局加赛。
- 回合结束先停止攻击与伤害判定，播放约 5.2 秒结束演出：冲击停顿 → 倒地 → KO / TIME OVER / DRAW 大字与语音 → 胜利播报。达到获胜目标后才显示结算；否则进入下一回合。倒地过程不使用拖影。
- 结算“重新开战”：沿用固化的本场配置与双方难度，比分、回合、生命、能量、闪避状态、飞行道具、抓取锁定及 AI 记忆全部重置；生成新随机种子。
- 结算“返回”：返回角色选择页，保留上次的角色和规则。
- 暂停：按 Esc 打开，提供继续战斗、重新开战、返回选人。窗口失焦自动暂停；战斗页不显示底部工具栏。
- 菜单使用页面返回按钮或 Esc 逐级返回；顶部品牌导航行隐藏，战斗通过暂停菜单返回。

## 练习

练习对手可选待机或持续防御，可开关无限能量点。时间固定为无限，不计比赛比分，击败对手后自动重置双方。血量倍率和地图仍可设置。无限能量仅影响练习，不影响正常对战。

## 存储与兼容

规则、角色选择和音画选项保存在 localStorage 的 `cricket-fighter-menu-v1`。读取时校验枚举和范围，损坏或禁用存储时使用默认值，游戏仍可运行。不保存进行中的比赛，不依赖账号和后端。

核心文件：

- `js/menu.js`：页面切换、菜单事件、结算与本场配置。
- `js/settings.js`：默认值、规则与选项校验、浏览器存储。
- `js/maps.js`：地图目录与显示元数据。
- `js/arena.js`：比赛状态、回合计时、暂停、重开与渲染。
- `js/combat.js`：基础生命、倍率、实际伤害与防御磨血规则。
- `js/presentation.js`：地图显示、无生命数字的 HUD、动态获胜标记和无限时间图标。

## 验证

`npm test` 覆盖倍率、直接伤害、防御磨血、短后摇、规则校验、资源与技能。`tools/browser-smoke.mjs` 从真实可见菜单进入比赛，检查存储恢复、地图加载、结算两按钮、重开配置、双方输入、练习与手机双指组合。它还监控资源失败和运行时异常，并拦截 Canvas 文字绘制检查没有生命数字。

`tools/browser-menu-smoke.mjs` 验证菜单方向键、Enter 确认、Esc 返回、箭头设置点按、键盘确认、即时保存/重置与图鉴详情；检查桌面及 844×390、932×430、960×432 和 568×320 手机横屏菜单不溢出，并生成预览截图。`tools/browser-mobile-smoke.mjs` 同时覆盖竖屏旋转、横屏、多指六键、长按防选中与各尺寸下选角和开战按钮可达性。

## 画面与音效

菜单使用整页宽度，战斗容器占满浏览器窗口，隐藏菜单页头与页脚。Canvas 随可用窗口比例调整绘制尺寸，场景铺满画面，不再固定 16:9 留黑边。人物保持等比，完整保留 960 宽的战斗范围；超宽窗口扩展两侧景物并保留至少 420 高的视野，地板对齐人物脚底，血条分别贴左右上方。手机方向键与六键以 56% 不透明度悬浮在画面上，不占用独立底栏。

## 手机横屏与触控

- 手机菜单、选角、地图、战斗和结算均采用横屏布局。点击开始、选择模式或重新开战时，在用户手势内尝试原生全屏及横屏锁定；全屏需要浏览器许可，iOS 等不支持的环境使用页面旋转回退，不承诺强制隐藏系统浏览器栏。
- 竖持时将整个界面旋转 90 度，并同步变换方向触点；实际横持后恢复正常方向。菜单以约 19.5:9 横屏（如 844×390）为设计基准，尺寸跟随 visualViewport / resize / orientationchange / fullscreenchange，在全屏与旋转过渡后再次校正，适配地址栏变化与安全区；竖屏回退使用逻辑横屏尺寸，不使用物理 vh 估算卡片高度。菜单可以滚动，战斗画面固定占满可用窗口。
- 左下默认八方向摇杆：上跳、左右移动、下防御、下后蹲防；前后随角色朝向判定。摇杆中心 22% 为死区，拖出边界仍保持方向，松开回中。
- “手机方向操作”可切换摇杆 / 十字按键，偏好保存在本机；旧默认值迁移为摇杆，重置也恢复摇杆。十字键中心为空挡，四角为斜方向，支持按住滑动换向，也可多指同时按左右方向和下方向。每个方向触区至少 44 像素。切换时清理所有触点，不遗留移动或攻击；两种方向方式均可组合方向招式。
- 右下两排六键：技能一 / 技能二 / 大招；拳 / 脚 / 闪避。前或下加拳脚沿用通用招式；技能各花 1 点，大招花 3 点，均无冷却。
- 使用 Pointer Events 和触点捕获，支持方向加攻击、方向加闪避等多指输入；手指移出按钮后松开、系统取消、失焦、暂停、切页、重开都清理输入。功能键快点按保留到一次逻辑帧，长按不连发。虚拟键与实体键状态分离。
- 触控操作 1P，用于单人、练习或本地双人；本地 2P 仍用外接键盘。电子斗蛐蛐隐藏操作层。选项保留自动 / 始终显示 / 隐藏；桌面小窗口不会自动显示触控键。
- 手机右上角有全屏切换入口；菜单返回按钮为其预留独立空间，战斗全屏和暂停位于右侧血条下方，避开中央视野；暂停及 KO 演出期间隐藏操作层，结算按钮正常可点。电脑仍使用 Esc 暂停。

实现位于 `js/mobile-controls.js` 和 `style/mobile-arena.css`；旧 `style/mobile.css` 属于上游演示，当前页面不加载它。`tests/mobile-controls.test.js` 验证方向变换、多指、短点按和取消，`tools/browser-mobile-smoke.mjs` 验证真实浏览器中的横竖屏布局及触摸。

音效默认开启，浏览器首次点击或按键后解锁音频。用户手动静音后保存偏好；旧版本默认静音存档仅迁移一次。全部攻击槽位无时间冷却，闪避保留独立间隔。

## 战斗声音

`js/audio.js` 使用 Web Audio 分层合成挥拳、踢击、命中重击、防御金属声、气功释放、爪击、抓投和最终一击。蓄势与释放分别跟随实际动作阶段触发，被打断的招式不会提前播放释放声。

大厅、选项和图鉴循环《街机集结》，选角与规则循环《准备出击》，结算循环《再战时刻》。三张地图分别使用原创程序谱曲：夕照天台《烈日决斗》（148 BPM）、午夜天台《霓虹追击》（138 BPM）、训练空间《极限热身》（126 BPM），循环鼓组、低音、和弦与旋律均有独立配置。使用音频时钟提前排程，暂停保留音乐，离开比赛切换对应页面主题。

内置英语街机播报使用本地合成语音 WAV，包含回合、Fight、紧凑的 KO、时间结束、平局及胜负。单人按 1P 视角播报 You win / You lose，观战与双人播报 Player one / two wins，结束大字同步结果。播报有短回声与低频处理，播报时音乐自动降低，结束后恢复。语音随静态资源打包，无联网语音服务、后台或 API Key。总音量和静音统一控制三类声音。

挥空与受击改用 `assets/audio/combat/` 中的 27 个原创短采样（9 类，各 3 个变体），包括拳／脚／爪的破风、拳击、踢击、重击、气功命中、抓摔和防御。命中由低频身体冲击、中频接触声与高频短促爆裂组成，干声收尾，不使用提示蜂鸣替代打击。每次轮换采样与轻微音高；运行 `node tools/generate-combat-sfx.mjs` 可重新生成。大招保留蓄力和释放音效，不再语音喊招。

## 选角与地图布局约定

手机游戏区域及按钮文字禁止长按选中、系统文字操作菜单和拖拽；原生设置选择框、滑块等保留正常交互。防长按不拦截菜单点击与规则区域滚动，战斗继续使用独立的多指指针输入。

选角顺序适用于观战、人机、双人和练习模式。选定角色只改变当前方的预览，点击锁定才移交选择权。双方就绪后仍可重选任意一方，另一方已锁定结果保留；回到选角页则重新从 1P 确认，保留上次角色作为预览。共享角色池可滚动，适配后续增加角色；键盘方向键切换并预览角色，Enter / 空格选中卡片，确认按钮锁定。

`style/match-lobby.css` 仅控制两个准备页面，使用手机逻辑横屏宽高，兼容原生横屏与竖屏旋转。左右玩家面板使用蓝／红提示当前方，文字同时标示选择状态；地图缩略图使用真实场景资源与对应夜景滤镜，训练地图使用网格预览。小屏保留地图、规则与开战入口，不压缩战斗画面或改变操作键位。

地图列表支持鼠标滚轮、滚动条和指针拖动。拖动按逻辑横屏坐标计算，兼容竖持旋转界面；移动超过 8 像素才视为滑动，结束时不误选地图，下一次点按正常选图。地图预览使用独立图片元素等比完整显示；训练空间显示网格。
