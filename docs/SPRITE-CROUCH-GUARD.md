# 蹲防动作

素材：`assets/characters/crouch-guard-v1.png`，通过内置 imagegen 生成并应用，参考 `arcade-fighters.png` 保留人物造型。实际为 1280×1280 透明 PNG，四个姿势：上排苍岚、下排赤锋，左侧蹲防、右侧格挡受力。裁切与脚底基准见 `js/animation-data.js`。

提示词：保留原创蓝衣白裤黑发、红衣黑裤棕发像素街机格斗人物，朝右，二列二行，完整人物隔离且保留透明空隙。双膝深弯下蹲、双前臂抬起保护面部胸部；第二帧为相同蹲姿格挡受力，前臂略被压回，不受伤、不跌倒、不出拳、不加特效、文字、拖影或背景；各帧保持头身比例与脚底基准。
