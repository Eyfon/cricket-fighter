# 战斗规则与玩法总览

完整的设计约束、角色制作流程和验收标准见 [设计总规范](./DESIGN-SPEC.md)。本文是当前运行数值的玩家向说明。

根据当前运行代码整理，2026-11-03。数值以 `js/roster.js` 为准；本文区分实际规则、招式参数和表现效果。

## 1. 游戏玩法

横向 1 对 1 格斗：通过走位、跳跃、拳脚、方向招式、闪避和角色技能击败对手。所有角色共用移动、防御、闪避和六种基础攻击，各自设计技能一、技能二、大招。

| 模式 | 玩法 |
| --- | --- |
| 电子斗蛐蛐 | 双方由本地规则 AI 控制，玩家选角色、地图与规则后观战 |
| 人机对战 | P1 玩家对 P2 AI |
| 本地双人 | 两人在同一键盘对战 |
| 练习 | P1 操作，P2 待机或防御木桩，可开启无限能量 |

流程：主界面 → 模式 → 选人 → 地图与规则 → 对战 → 结束演出 → 重开或返回。地图有夕照天台、午夜天台、网格训练场，各有 BGM。游戏在浏览器本地运行，无需战斗后端，没有网络联机。

默认每回合 60 秒，先赢 2 回合获胜。时间可选 30／60／90 秒或无限，获胜目标可选 1／2／3 回合。双方使用同一血量倍率 1／2／3／5，默认 1 倍，基础血量 100。倍率只增加生命上限，不改变伤害。战斗画面只显示血条，不显示具体 HP 数字。

生命归零结束回合；时间结束比较剩余生命，血量相同则不计胜场，继续下一回合。新回合重置生命、能量、动作和保护计时，保留胜场。KO 依次经过最终一击、倒地、KO 字样与语音、胜利播报，再显示结算选项。Esc 暂停；窗口失焦会自动暂停。

## 2. 操作与基础攻击

| 功能 | P1 | P2 |
| --- | --- | --- |
| 左右移动 | A／D | ←／→ |
| 跳跃 | W | ↑ |
| 防御 | S | ↓ |
| 防扫腿 | 下＋后方向 | 下＋后方向 |
| 拳、脚、闪避 | J／K／L | 小键盘 1／2／3 |
| 技能一、技能二、大招 | U／I／O | 小键盘 4／5／6 |
| 暂停 | Esc | Esc |

“前／后”相对于对手方向判断。单按后方向可后退，不自动防御；当前防御采用下键，下＋后为蹲防。方向招式在地面使用，空中按前＋拳脚仍是普通空中拳脚。攻击按下时触发，按住不会自动连续攻击。

| 共用攻击 | 输入 | 基础伤害 | 前摇／有效／后摇（帧） | 特征 |
| --- | --- | ---: | --- | --- |
| 直拳 | 拳 | 4 | 6／4／5 | 快速近身，上身判定，可空中使用 |
| 中踢 | 脚 | 6.5 | 10／5／7 | 比直拳更远，可空中使用 |
| 突进重拳 | 前＋拳 | 8 | 11／7／8 | 地面突进，不击飞 |
| 飞踢 | 前＋脚 | 8.5 | 12／8／9 | 前向突进，不击飞 |
| 上勾拳 | 下＋拳 | 7 | 9／7／8 | 对空，击飞 |
| 扫腿 | 下＋脚 | 7 | 10／6／8 | 下段攻击，未蹲防可被扫倒 |

六种攻击均不耗能，无时间冷却。逻辑按 60Hz 模拟，1 帧约 16.7ms。

## 3. 能量与伤害

能量由蓄能进度和能量点构成。蓄能每满 100 转为 1 点，最多 3 点；满点不储存第四点。技能一、二各消耗 1 点，大招消耗 3 点，均无时间冷却。释放时只扣点，不扣未满的蓄能进度。成功开始招式才扣点，中途被打断不退还。

普通攻击命中增加配置的蓄能：直拳 12、中踢 14、四种方向攻击各 9；被防御时施放者获得该值的 40%。受击方每次正常受击获得 10 蓄能，防御命中获得 3。打空不因命中规则获得能量，角色技能的 `gain` 均为 0。

伤害直接使用招式配置，没有全局乘 0.5 的结算。防御通常承受 25% 芯片伤害，芯片可致死。扫腿需下＋后防御。抓取无视防御，苍岚大招也不可防御；可利用跳跃、闪避或命中前打断应对。飞行道具互相穿过，不对消。

## 5. 出招、连招与打断

攻击通常分为前摇、有效阶段、后摇：前摇准备，有效阶段判定命中，后摇收招。投射物、范围爆气、落地砸击、抓取各有独立结算时序。普通单次攻击通常只命中一次；多球、连打按各自分段结算。

直拳实际命中且未被防御后，可在允许窗口取消剩余动作，接脚、方向攻击、技能或大招。当前不是任意招式互相取消。攻击收招阶段支持约 0.1 秒提前输入；受击硬直、防御硬直、倒地或被抓取时不能出招，也不缓存技能等待自动释放。

| 正在释放的招式 | 可以打断它的命中 | 不能打断它的命中 |
| --- | --- | --- |
| 普通拳脚、方向招式 | 通常可被正常受击打断 | 闪避或保护使该次命中无效的情况 |
| 技能一／二 | 实际附带击飞或倒地的攻击 | 没有击飞、倒地效果的普通命中 |
| 大招 | 技能一、技能二或大招 | 普通拳脚、前／下方向招式 |

抗打断只免除该次硬直、击退等控制，仍正常扣血；生命归零正常 KO。上勾拳与扫腿可以打断小技能；它们不属于耗能角色技能，不能打断大招。若扫倒被防扫倒保护抵消，则它不能靠这次已失效的倒地打断小技能。

同时接触的普通近战攻击先比较进入有效阶段的进度，进度更早者优先；完全相同则按固定玩家顺序。先受击者攻击失效，不再用过期判定反向命中。此规则不意味着所有飞行道具或抗打断对攻都绝不会互相造成伤害。

## 6. 状态与保护

| 状态／标记 | 含义 |
| --- | --- |
| 待机／行走 | 可以移动、起跳或开始招式 |
| 空中 | 受重力影响，可普通拳脚攻击，按住方向可移动 |
| 防御／蹲防 | 降低可防御攻击的伤害；蹲防可挡扫腿 |
| 攻击 | 运行指定招式的前摇、有效、后摇与事件 |
| 受击硬直 | 暂时不能正常行动或出招 |
| 防御硬直 | 格挡后的短暂限制，允许持续保持防御 |
| 击飞 | 垂直速度被改变；可以只击飞而不倒地 |
| 倒地 | 地面倒地动画持续 0.72 秒，不能主动出招；附带击飞时从落地开始消耗倒地计时 |
| 闪避 | 持续 0.28 秒；剩余时间大于 0.06 秒时规避一般命中，尾段可受击 |
| 抓取中／被抓取 | 施放者播放连打，对方的位置和行动由抓取过程控制 |
| 抗打断 | 招式规则标记，不是免伤或独立的技能冷却 |
| 防扫倒 | 从被扫倒时起 5 秒内，不再被扫腿重复击倒；仍受伤、硬直与其他控制，不被重复扫腿刷新 |
| 脱身保护 | 长时间连续受控后的短暂恢复窗口 |
| KO | 生命归零，停止正常出招，进入结束演出 |

闪避单按原地闪；左／右＋闪避向对应方向移动。闪避有独立的 0.8 秒重复限制，其他攻击没有时间冷却。

防止无限控制的措施：连续受击硬直逐步衰减，最低约为基础比例的 45%；连续受击达到 6 次或受控累计约 0.75 秒时，符合条件者获得约 0.22 秒脱身窗口。抓取结束另有至少 0.34 秒短保护，避免立即再次抓取。具体计时随模拟更新，不能将这些条件理解为任意情况下的绝对免控承诺。

墙角反推只在贴身直接近战触发：双方水平距离不超过 140、垂直距离不超过 100，受击方位于对应边缘。投射物、范围爆气、砸地和抓取不会反推施放者，连续压制脱身时也遵守近战限制。

## 7. 属性与类型词典

| 参数 | 含义 |
| --- | --- |
| `hp / maxHp` | 当前／最大生命 |
| `speed / jump` | 水平移动速度／初始起跳速度大小 |
| `width / height` | 受击框尺寸，与人物画面大小分开 |
| `facing / ground` | 朝向／是否接触地面 |
| `vx / vy / pushVx` | 水平速度／垂直速度／独立击退速度 |
| `energyPoints / meter` | 已获得能量点／未满一格的蓄能 |
| `startup / active / recovery` | 前摇／有效／后摇，单位帧 |
| `damage / chipRatio` | 完整命中伤害／防御芯片比例 |
| `stun / knockback` | 基础受击硬直帧数／水平击退强度 |
| `launch / knockdown` | 击飞初速度／是否附带倒地 |
| `cost / gain` | 释放耗点／命中增加的蓄能 |
| `box` | 近战攻击框，相对脚底原点，朝左自动镜像 |
| `range / minRange` | 主要供 AI 选择技能的估计距离；不替代实际碰撞判定 |
| `burstRange` | 范围攻击使用的中心距离；当前用水平距离判断 |
| `groundOnly / low / unblockable` | 仅地面发动／下段攻击／不可防御 |
| `cancel` | 实际命中后允许取消接入的招式名单 |
| `projectile` | 飞行速度、半径、存活时间、手部发射偏移与分球时间等 |
| `grab` | 抓取持续时间、各段命中时间和伤害 |
| `sprites / phases / grabTimeline` | 动作图集、分阶段帧序列、连打动画时间点 |

角色招式槽位为：直拳、中踢、前拳、前腿、下拳、下腿、技能一、技能二、大招，共九个；输入仍只需方向加六个功能键。

当前角色主要使用四种效果类型：`dash` 突进、`projectile` 投射物、`burst` 范围爆发、`grab` 抓取。引擎还兼容 `rise` 自身上升、`rush` 多段突进，当前最终角色配置不必使用所有效果。AI 标签包括牵制、对空、接近、终结、远程、抓取，用来影响选择权重，不是额外伤害属性。

目前没有独立的暴击率、护甲、防御力、属性克制、装备或成长等级。抗打断、击飞、倒地、破防等均由招式或战斗状态决定。
